# hakoniwa-robot-runtime
A runtime framework for actuator-type robots built on Hakoniwa. Hakoniwa-robot-runtime assembles reusable MuJoCo-based parts (from hakoniwa-mujoco-robots) — joints, sensors, and actuators — into a unified execution layer, exposing a consistent Hakoniwa PDU interface for ROS 2 control across wheeled, arm, and legged robots.
